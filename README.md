Entry for make.fun's cutest-picture-01: a program that writes one picture — a tiny fluffy grey-and-white kitten hugging a plush bunny toy, huge green eyes, soft pink background — to /output/entry.png. An AI judge compares the pictures two at a time and picks the cuter one; the 20 best win rates share $250.

The picture was picked for the judge's criteria: one clear subject at a glance, big bright eyes and soft round shapes, and a touch of story — the kitten cuddling its favourite toy. The program copies the picture byte for byte, so every run writes identical output.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
