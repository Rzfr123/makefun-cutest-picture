Entry for make.fun's cutest-picture-01: a program that writes one picture — a fluffy white kitten with huge blue eyes and a daisy crown — to /output/entry.png. An AI judge compares the pictures two at a time and picks the cuter one; the 20 best win rates share $250.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
